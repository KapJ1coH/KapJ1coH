## Fun plugins

If you feel like your shell is missing some cool plugins, say no more.

- Your new colorful cli shell: [starship](https://github.com/starship/starship)
- Terminal emulator: [Wezterm](https://wezterm.org/)
- Amazing tiling manager with a cool task bar replacement: [glazeWM](https://github.com/glzr-io/glazewm) - Windows
- Scrolling Compositor for your linux distro: [niri](https://github.com/niri-wm/niri) - Linux
- UI Shell for this compositor ^: [noctalia shell](https://noctalia.dev/) - Linux
- File browser [yazi](https://github.com/sxyazi/yazi)
- The best git client ever [lazygit](https://github.com/jesseduffield/lazygit) he also made a cool docker tool, [lazydocker](https://github.com/jesseduffield/lazydocker)
- Smart memory for the `cd` command [zoxide](https://github.com/ajeetdsouza/zoxide)
- Nice alternative for `ls` and `dir` [eza](https://github.com/eza-community/eza)
- For some powershell features, see my [pwsh config](https://github.com/KapJ1coH/PowerShell/blob/main/Microsoft.PowerShell_profile.ps1)
